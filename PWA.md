# PWA.md — устанавливаемое приложение: что построено и где проходит граница

> Документ корпуса проекта, форма «правило → проверка → пример»: позже он станет навыком.

**Прогрессивное приложение** — это сайт, который телефон ставит к себе как обычное приложение: значок на
экране, запуск без адресной строки, своя заставка. Ни магазинов, ни проверок, ни отдельных сборок под iOS
и Android — тот же сайт.

---

## Закон 1. Манифест — на язык, а не один на сайт

**Правило.** Каждая языковая версия ссылается на свой `/<язык>/manifest.webmanifest`; собирает их общий
строитель `lib/pwa/manifest.ts`. Корневой `/manifest.webmanifest` остаётся для языка по умолчанию.

**Почему.** Установленное приложение подписано на домашнем экране именем из манифеста и открывается с его
`start_url`. Один манифест на весь сайт означал, что испаноязычный посетитель ставит себе приложение с
английским именем, открывающееся на английской главной, — и переименовать значок он уже не сможет. Это то
же самое, что один `<html lang>` на все языки, только на телефоне и навсегда.

**Проверка.** `npm run check:pwa` + `curl /ru/manifest.webmanifest` — `lang`, `name`, `start_url` и ярлыки
на нужном языке.

---

## Закон 2. `id` обязателен

**Правило.** Манифест объявляет `id` (у нас — стартовый адрес языка).

**Почему.** Без `id` система опознаёт установку по `start_url`. Смена стартового адреса — например, при
подключении домена — превращается во ВТОРОЕ приложение рядом с первым вместо обновления существующего, и
у пользователя на экране оказываются два одинаковых значка.

---

## Закон 3. Имя приложения — не заголовок страницы

**Правило.** `name` берётся из имени сайта, а не из `metaForLang().title`.

**Почему.** Заголовок пропущен через шаблон (`%s | Сайт`), и на домашнем экране это выглядит как
«Магазин | Магазин Иванова». Найдено живой проверкой манифеста, а не рассуждением.

---

## Закон 4. Иконки нарезает панель из одного изображения

**Правило.** Владелец загружает одно изображение; набор (192, 512, **maskable**, `apple-touch-icon`,
`favicon` разных размеров, включая `.ico`) генерирует панель.

**Почему maskable отдельно.** Android обрезает значок под форму своей оболочки — круг, скруглённый
квадрат, каплю. Иконка без запаса по краям теряет часть рисунка.

**Граница.** Пока владелец ничего не загрузил, в манифесте иконок нет — и приложение установить нельзя.
Это не дефект кода: значок приложения не может быть чужим. Первое, что стоит сделать в настройках, —
загрузить логотип.

**Проверка.** `npm run check:pwa` требует наличия `maskable` в строителе.

## Закон 5. 🔒 Сервис-воркер НИКОГДА не отдаёт страницу из кеша первой

**Правило (`public/sw.js`):**

- **документы (HTML)** — только из сети; кеш используется исключительно при её отсутствии;
- **статика по хешу** (`/_next/static/…`) — из кеша: её адрес меняется с каждой сборкой, устареть она не
  может физически;
- **всё остальное** (api, изображения) — воркер не трогает.

**Почему это главный закон файла.** Кеш страниц — источник самой дорогой жалобы в таких проектах: «я
поменял текст, а в приложении старый». У нас это опаснее вдвойне: панель управления меняет тексты и
настройки БЕЗ пересборки, то есть кешированная страница расходится с настоящей в ту же минуту. При
выбранной стратегии устаревшая страница невозможна по построению.

**Что это даёт и чего не даёт.** Даёт: мгновенное повторное открытие, работу уже виденных страниц без
сети. Не даёт: страницу, которую посетитель ещё не открывал, — офлайн честно покажет ошибку сети.
Отдельной офлайн-страницы нет намеренно: она потребовала бы слов на всех языках, то есть партии перевода.

**Проверка.** `npm run check:pwa` падает на воркере, отдающем документы из кеша (проверено негативным
контролем).

**Где воркера не будет.** В режиме без домена сайт работает по http, а браузер регистрирует воркер только
в защищённом контексте. Приложение при этом полностью работоспособно — теряется только офлайн.

## Закон 6. Цвет темы — отдельно для светлого и тёмного оформления

**Правило.** `generateViewport` объявляет `themeColor` под обе схемы.

**Почему.** Иначе полоса состояния на телефоне с тёмной темой красится не в тот цвет, и установленное
приложение выглядит чужим.

## Чего сознательно НЕТ

| Не сделано | Почему |
|---|---|
| Своя кнопка «установить» | её слова обязаны существовать во всех языках (правило переиспользуемых элементов), а это партия перевода. Установку предлагает сам браузер — значком в адресной строке и пунктом меню |
| Заставки iOS | требуют картинок под каждый размер экрана; это работа генератора иконок в панели, не кода приложения |
| Офлайн-страница | см. закон 5 |

Пункты не «забыты» — они названы, и у каждого написана причина. Появится партия перевода — первый пункт
закрывается за час.

| Команда | Что ловит |
|---|---|
| `npm run check:pwa` | манифест мимо общего строителя; отсутствие языкового манифеста; пропавшие поля и `maskable`; невключённую регистрацию воркера; **воркер, отдающий страницы из кеша** |
