# Очередь переезда koleso-balansa

Порождена из дерева (`../FS-TREE.md`) и пяти кейсов (`../USE-CASES/`) 2026-08-22.
**Тринадцать шагов.** Первый — каркас, последний — данные; между ними по одной возможности за шаг.

В проекте владельца эта очередь лежала бы в `development-docs/development-steps/new-steps/` под своими
номерами. Здесь она под деревом: это пробный разбор ЧУЖОГО проекта внутри нашей мастерской, и смешивать
его с шагами платформы нельзя.

| № | Шаг | Кейс | Зависит от |
|---|---|---|---|
| m01 | Каркас: адреса, восемь таблиц, вход, роли | все | — |
| m02 | Сферы жизни | 01 | m01 |
| m03 | Сегменты сферы | 01 | m02 |
| m04 | Замер сегмента | 01 | m03 |
| m05 | Колесо баланса — экран | 01 | m04 |
| m06 | Привычки | 02 | m02 |
| m07 | Расписание привычки | 02 | m06 |
| m08 | Отметка дня | 02 | m07 |
| m09 | Пульс дня и статистика активностей | 02 | m08 |
| m10 | Связь коуч ↔ клиент и кокпит коуча | 03 | m01 |
| m11 | Приглашение клиента | 04 | m10 |
| m12 | Подписка: пробный период, тариф, окончание | 05 | m01 |
| m13 | Перенос данных из старой базы и файлов | — | m01–m12 |

**Тринадцатый стоит особняком:** это не возможность, а разовая операция по отдельному доступу владельца —
и до неё цена ошибки в любом шаге почти нулевая.
