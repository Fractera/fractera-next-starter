# m03 — Сегменты сферы

**Кейс.** `01-client-measures-wheel`. **Зависит от** m02.

**Что делаем.** `p1_segments`: сегмент принадлежит сфере, имеет имя, описание, значок. Страница
`balance/segments`, логика в `lib/products/p1/segments.ts`.

**Доказательство.** Сегмент создаётся внутри сферы; удаление сферы уносит её сегменты, а не оставляет
сиротами, как позволяет схема оригинала.

🔒 Поля напоминаний заводим, рассылку в этом шаге НЕ делаем — её делает канал платформы отдельным шагом.
Поле без доставки — обещание, которого код не держит.
