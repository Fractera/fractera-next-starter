# m04 — Замер сегмента

**Кейс.** `01-client-measures-wheel`. **Зависит от** m03.

**Что делаем.** `p1_segment_marks`: дата, значение, комментарий. Ввод — островок на странице сегментов;
запись через `lib/products/p1/segments.ts`, владелец берётся из сессии.

**Доказательство.** Замер сохраняется и виден в истории сегмента; запрос с чужим идентификатором клиента
отвергается службой — проверяется прямым вызовом.

🔒 Дата — тип базы, не строка. В оригинале `date String`, и периоды сравнивались как текст.
