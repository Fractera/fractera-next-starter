# m05 — Колесо баланса, экран

**Кейс.** `01-client-measures-wheel`. **Зависит от** m04.

**Что делаем.** Страница `balance/statistics/wheel`: агрегат последних замеров по сегментам сферы,
отрисовка одним графическим примитивом стартера.

**Доказательство.** Числа на колесе совпадают с содержимым `p1_segment_marks` за выбранный период —
сверяется прямым запросом к слою данных.

🔒 Одна библиотека графиков на продукт. В оригинале стояли ApexCharts и Recharts одновременно.
