# m07 — Расписание привычки

**Кейс.** `02-client-keeps-habits`. **Зависит от** m06.

**Что делаем.** `p1_activity_schedule`: тип расписания, дни недели, число раз за период.

**Доказательство.** Привычка с расписанием «пн, ср, пт» ожидается именно в эти дни и не появляется в
остальные.

🔒 Дни недели — перечисление, а не свободный массив строк: `days String[]` в оригинале принимал что угодно.
