# m11 — Приглашение клиента

**Кейс.** `04-coach-invites-client`. **Зависит от** m10.

**Что делаем.** `p1_invites`: одноразовый код с автором и сроком. Коуч выпускает ссылку; клиент проходит
по ней вход платформы, код обменивается на связь коуч ↔ клиент и гасится.

**Доказательство.** Ссылка приводит нового человека в кокпит уже связанным с коучем; повторный проход по
той же ссылке отвергается.

🔒 **Личность не берётся из адреса.** В оригинале идентификатор приходил параметром и клался в
`localStorage` — подставив чужой, человек входил чужим. Здесь код обменивается на сессию, и только.
