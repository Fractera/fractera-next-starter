# m12 — Подписка: пробный период, тариф, окончание

**Кейс.** `05-subscription-lifecycle`. **Зависит от** m01.

**Что делаем.** `p1_subscriptions`: состояние, тариф, начало и конец. Длина пробного периода — одно
значение в `lib/products/p1/subscription.ts`. По окончании кокпит сужается до страницы продления.

**Доказательство.** Новый человек получает пробный период; после сдвига даты окончания в базе кокпит
сужается, после продления открывается снова.

🔒 Одно значение на длину пробного периода. В оригинале константа `604800000` повторена в двух маршрутах
слово в слово.
