# Коуч смотрит прогресс клиента

**Сценарий.** Коуч видит список своих клиентов, открывает карточку и смотрит те же сферы, замеры и
привычки, что видит клиент, — но только у своих.

**Откуда прочитано.** Модель `Students` (связь коуч ↔ клиент), `app/api/students/route.ts`,
`app/api/user/get-my-coach/route.ts`, экраны `app/dashboard/clients`, `app/dashboard/coaches`.

```ts
// app/api/segments/route.ts — попытка проверить право
const canCreate = user.clerkUserId === clerkUserId ||
  user.students.some(student => student.userId === user.id);
```

**Что переносится.** Связь коуч ↔ клиент, доступ коуча к данным своих клиентов, запрос на подключение.

🔒 **Чего НЕ повторяем.** Правило доступа переписано в каждом маршруте руками, и в приведённом виде оно
проверяет `student.userId === user.id` — то есть свойство самого пользователя, а не то, что запрошенный
клиент принадлежит этому коучу. У нас проверка живёт **одной функцией** в `lib/products/p1/coaching.ts`,
и каждый маршрут зовёт её.
