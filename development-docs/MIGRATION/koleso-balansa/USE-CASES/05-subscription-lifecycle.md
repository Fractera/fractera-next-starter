# Подписка: пробный период, тариф, окончание

**Сценарий.** Новый человек получает пробный период; дальше у него тариф со сроком. По окончании доступ
к кокпиту сужается.

**Откуда прочитано.** Поля `User`: `trialPeriod`, `typeSubscription`, `statusSubscription`,
`startSubscriptionDate`, `endSubscriptionDate`; `app/api/user/fetch-coach/route.ts`,
`app/api/user/fetch-student/route.ts`.

```ts
// повторено ДВАЖДЫ, в двух файлах слово в слово
const trialPeriodMilliseconds = 604800000; // 7 дней в миллисекундах
const endTrialDate = addMilliseconds(currentDate, trialPeriodMilliseconds);
```

**Что переносится.** Пробный период, тариф, срок, состояние подписки, сужение доступа по окончании.

🔒 **Чего НЕ повторяем.** Длина пробного периода — константа, размноженная копией по двум маршрутам:
поменяв её в одном, владелец получит два разных правила и не узнает об этом. У нас она живёт в
`lib/products/p1/subscription.ts` одним значением. Поля подписки уезжают в `p1_subscriptions`, а не в
карточку пользователя: человек принадлежит платформе, подписка — продукту.
