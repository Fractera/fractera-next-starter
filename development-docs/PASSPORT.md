# PASSPORT — what this project is

**The fifth address of memory.** The other four say what was planned, where the work stands and how it
ended. This one says **what the project IS and by what rules it is built** — and it is the only place
that knowledge has.

**The agent writes this file and keeps it current.** It is not the product dossier
(`PRODUCTS-CONFIG/<id>.json`, which only the control panel may write): the dossier holds the CASES, the
passport holds the DECISIONS.

🛑 **START LIGHT — the project does not start while a ⛔ stands.** Not "it would be good to read this":
while any section below is marked ⛔, you ask the owner and wait. There may be no cases at all — he is
free not to write any — and then this file is the only source of understanding you have.
