# development-docs — только то, что растёт само

**Закон папки (владелец, 2026-08-22): здесь живут ЭВОЛЮЦИОНИРУЮЩИЕ документы — те, что агент пишет
сам, по ходу работы.** Всё остальное здесь чужое и подлежит переезду.

Три адреса для трёх родов знания, и путать их дорого:

| Род знания | Где живёт | Почему там |
|---|---|---|
| **закон** — действует всегда, повода нет | `CLAUDE.md` | доставить его вовремя нечем, значит он читается всегда |
| **процедура** — нужна по конкретному поводу | навык `.claude/skills/<имя>/SKILL.md` | приходит в минуту, когда за неё берутся, и не занимает контекст до этого |
| **опыт** — то, чего вчера не знали | **эта папка** | пишется в момент, когда понято; никем не задаётся заранее |

## Что здесь по праву

| Документ | Кто пишет | Когда |
|---|---|---|
| `ANTI-PATTERNS.md` | агент | подход оказался тупиком — короткий закон, ~700 знаков |
| `reports/` | агент | подробный разбор: `errors-…` — один отказ и его механизм; `feature-…` — законченная фича |
| `GLOSSARY.md` | агент | появилось слово, которым пользуется больше одного документа |
| `TRANSLATION-DEBT.md` | агент | завёл маршрут или компонент на одном языке |
| `development-steps/` | агент | планы, живое состояние (`current-steps.md`) и итоги |
| `API-MAP.md` | сборка | порождается `npm run build:api-map` — артефакт, не текст |

## Чего здесь быть не должно

Документ, который **дан** (его пишет человек, агент ему подчиняется), и документ, который **повторяет**
навык или инструкцию, — не эволюционируют. Копии расходятся, и расходятся в том месте, куда никто не
смотрит.

## Как проверить себя перед тем, как завести файл ЗДЕСЬ

Три вопроса подряд:

1. Это пишу я по ходу работы, или это мне дали? Дали — папка чужая.
2. У этого есть повод, в который его надо прочитать? Есть — это навык.
3. Это действует всегда и повода не имеет? Тогда это `CLAUDE.md`.

Ни один ответ не подошёл — файл, скорее всего, не нужен вовсе.
