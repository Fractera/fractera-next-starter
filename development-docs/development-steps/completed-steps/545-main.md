# 545 — Матрица возможностей: 78 операций, ноль провалов платформы

**Что сделано.** Каждая возможность слоя данных проверена живьём одной командой:
`PUBLIC_DATA_HOST=https://data.aifa.dev bash /opt/fractera/scripts/probe-capabilities.sh`

**78 операций, провалов 0, блоков 0; два прогона подряд дали то же.** Вся дверь · вся база (создание,
чтение, поиск, пагинация, правка, удаление строки, CREATE/ALTER/DROP, SELECT с параметрами) · вся
медиатека, включая весь путь иконок · все векторы (свой вектор и расчёт моделью, поиск словами,
удаление) · весь граф знаний (загрузка, ответ по документу, удаление с проверкой списка) · карта ·
каналы · настройки панели · журнал развёртываний. Семь негативных контролей.

**Уборка проверена по каждому складу после ДВУХ прогонов:** медиа 0, наборов иконок 0, векторов 0,
временных таблиц 0, документов 0. Сайт 200, панель отвечает, значок сайта на месте.

**Найдено и исправлено в ПРОДУКТЕ, а не в проверке.** У платформы не было удаления набора иконок:
создать значок сайта было можно, отменить нельзя. Добавлен `DELETE /media/icons/:id` — файлы и запись
уходят вместе (`ec0add4`).

**Ошибки шага — пять, и все мои, ни одной у платформы:** чужой путь к образцу, `page_size` ниже
минимума схемы, честный 404 пустого склада, `id` внутри `item`, удаление документа по имени вместо id
при асинхронном удалении. Урок записан в скрипт: **ожидание пишется по дословному ответу службы, а
проверяется РЕЗУЛЬТАТ, а не код ответа.**

**Приёмка холодным агентом пройдена (два круга, 2026-08-23).** Агент строил склад запчастей: три
таблицы, четыре двери, две страницы, семантический поиск с сортировкой складов по реальному
расстоянию; 21 гейт зелёный, артефакты снесены той же операцией. Первый круг сломался на карте
(двойной адрес службы), после правки навыка второй прошёл её чисто.

**Две находки вошли в `use-map` живыми числами:** соседние маршруты отвечают в РАЗНЫХ единицах
(`route` — километры и минуты, `matrix` для той же пары — метры и секунды: `4.29`/`10.5` против
`4303.9`/`632.1`), и матрица НЕСИММЕТРИЧНА (`4303.9` туда против `4039.4` обратно). Прочитать ячейку
матрицы как километры — ошибиться в тысячу раз числом, которое на экране доставки выглядит
правдоподобно.

**Решение владельца, дословно.** «Во всех пяти навыках все возможные способы чтения записи удаления
работают — только тогда можно говорить, что задача сделана.»
