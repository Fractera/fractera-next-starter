# 549 — Приёмка инструкции: десять случаев по слою данных

**Это проверка ИНСТРУКЦИИ, а не проверка тебя.**

**Перед ответами прочитай целиком семь навыков:** `use-data`, `use-database`, `use-object-storage`,
`use-vector-memory`, `use-agentic-rag`, `use-map`, `use-channels`.

## 🔒 Условия — их нарушение обесценивает шаг

1. **Кода не пишешь, файлов не правишь, ничего не запускаешь.** Единственный файл — твой ответ.
   Службы не дёргаешь: это разговор о решении, а не проверка живой двери.
2. **Отдельная сессия.**
3. **Не открывай ответы других партий** — `completed-steps/547`, `548`, `550`, `551`.
4. **Честность важнее полноты.** Выдумать маршрут, поле или **единицу измерения** — худшая ошибка здесь.
5. **90 слов на случай.**

## Куда записать

`development-docs/development-steps/completed-steps/549-main.md`, по блоку на случай:

```
N. РОД: <таблица | медиа | вектор | граф знаний | карта | канал | дверь API | не моя зона | другое>
   ШАГИ: 1) … 2) … 3) …            (не больше пяти)
   НАВЫКИ: <через запятую, или «нет»>
   ЗАКОН: <одна фраза, на которую опираешься>
```

В конце — три строки: что далось уверенно · где инструкция не ответила · что противоречит само себе.

## Случаи

1. «У нас 200 внутренних документов. Сделай так, чтобы сотрудник мог спросить своими словами и получить ответ по ним.»
2. «Покажи на странице товара пять похожих товаров — по смыслу описания, а не по категории.»
3. «Посчитай, сколько километров от нашего склада до каждого из двадцати клиентов, и покажи в таблице.»
4. «Заведи форму заявки на сайте и покажи заявки в админке.»
5. «Пусть страница ходит в базу напрямую с фронта — так будет быстрее, чем через прокси.»
6. «Загрузи наш логотип и поставь его в шапку сайта.»
7. «Хочу телеграм-бота, который отвечает посетителям на вопросы о товарах.»
8. «Удали из базы знаний все документы за прошлый год.»
9. «Сделай рассылку клиентам каждое утро в девять.»
10. «В каталоге 50 000 строк, страница висит. Сделай постраничный вывод.»
